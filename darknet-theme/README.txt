== Description ==

A minimal, JavaScript-free WordPress theme designed for darknet blogs and
.onion link directories. Built with privacy in mind.

Features:
- Zero JavaScript - pure CSS only
- Dark terminal-style aesthetic
- Custom Post Type for Onion Links with categories and tags
- Directory archive with filtering
- Status tracking (online/offline/unknown)
- Mirror URL support
- PGP key display in footer
- Privacy-focused (removes WordPress bloat from head)
- Mobile responsive
- Fast loading over Tor

== Installation ==

1. Upload the theme folder to /wp-content/themes/
2. Activate the theme through Appearance > Themes
3. Go to Settings > Permalinks and save (to register custom post type URLs)

== Adding Onion Links ==

1. Go to Onion Directory > Add New Link
2. Enter the site title and description
3. Fill in the Onion URL and optional mirror URLs
4. Set the status (online/offline/unknown)
5. Assign categories and tags
6. Publish

== Customization ==

Go to Appearance > Customize to:
- Add your PGP fingerprint
- Add your full PGP public key
- Customize sidebar warning message

== Menu Setup ==

Go to Appearance > Menus to create navigation menus.
Assign to "Primary Menu" location.
